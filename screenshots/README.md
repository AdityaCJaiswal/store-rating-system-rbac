## Screenshot Guidelines

- Use high resolution (1920x1080 or higher)
- Capture the full interface, not just partial screens
- Ensure all text is readable
- Use consistent styling and branding
- Include both desktop and mobile views if applicable
- Show different user roles and their respective interfaces

## File Naming Convention

- Use kebab-case for file names
- Include descriptive names that match the functionality
- Use PNG format for best quality
- Example: `admin-dashboard.png`, `store-owner-dashboard.png`
